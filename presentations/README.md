### Regenerate

1. Place the baseline deck at  
   `/Users/manishmohan/Documents/Self-Healing_Playwright_Framework_Technical_Briefing.pptx`  
   (or update `BASELINE` in the script).
2. Install deps: `pip install -r requirements-presentation.txt`
3. Run:

```bash
python scripts/generate_presentation_from_baseline.py
```

Output is written to this folder.
